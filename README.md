# Chef's Menu Manager - Final PoE (MAST5112)

## Change Log – Changes since Part 2

### New Features Added
- Edit existing menu items
- Delete menu items (with confirmation)
- Search menu items by name
- Filter menu items by course (Starter, Main Course, Dessert, Drink)
- Clear search and filter
- Menu Statistics section:
  - Total number of menu items
  - Average price of all items
  - Number of items per course

### Improvements & Refactoring
- Improved overall layout and visual design
- Better form validation and user feedback (success & error messages)
- Added confirmation dialog before deleting items
- Cleaner and more consistent UI
- Used meaningful variable and function names
- Improved code organisation
- Better empty state messages
- More user-friendly experience overall

### How to Run
1. Install dependencies: `npm install`
2. Start the app: `npx expo start`
3. Scan the QR code with Expo Go
